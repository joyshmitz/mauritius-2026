# Маврикій 2026 — сайт поїздки

Єдине джерело правди для шістьох. Статичний сайт: жодного бекенду, все в цих файлах.

```
index.html      ← сам план (редагувати тут)
ds-base.js      ← підвантажує стилі дизайн-системи
image-slot.js   ← слот для фото (перетягуванням)
_ds/…           ← стилі + бандл дизайн-системи
Маврикій 2026 — план шістьох (офлайн).html  ← одним файлом, працює без інтернету
```

## Куди це викласти

Сайт має жити за **однією постійною адресою**, а в чаті лежить лише посилання на неї.

**GitHub Pages** (рекомендовано, бо оновлення = коміт):
```bash
cd /Users/sd/projects/Mauritius
git init && git add . && git commit -m "Маврикій 2026: план"
gh repo create joyshmitz/mauritius-2026 --public --source=. --push
```
Далі Settings → Pages → Source: `main`, папка `/` (або `/site`). Адреса:
`https://joyshmitz.github.io/mauritius-2026/`

**Netlify Drop** — швидка альтернатива: netlify.com/drop, перетягнути папку `site/`.
Мінус: кожне оновлення — новий drop, адреса випадкова.

⚠️ Google Drive для сайту не годиться — він показує HTML як файл, а не як сторінку.
Drive — це сховище джерел і таблиць, не хостинг.

| Маврикій 2026 — витрати | журнал витрат і баланси | https://docs.google.com/spreadsheets/d/1dcejzNFN0MElq8OpvSUZhXZCMcJMkQC3CFCs8E60fM4/edit |

Обидві вже опубліковані як CSV і **підключені до сайта** — блоки «Живий статус» (розділ
«Зараз») і «Журнал витрат» (розділ «Гроші») читають їх при кожному відкритті сторінки.
Якщо колись доведеться перепідключити:

1. У таблиці: **Файл → Оприлюднити в інтернеті** (File → Publish to web).
2. Вибрати аркуш, формат — **Значення, розділені комами (.csv)**, натиснути «Опублікувати».
3. Скопіювати посилання виду `https://docs.google.com/spreadsheets/d/e/2PACX-…/pub?gid=0&single=true&output=csv`.
4. Вставити його в `index.html`, у блок на початку скрипта:

```js
const SHEETS = {
  status:   'сюди CSV-посилання таблиці статусу',
  expenses: 'сюди CSV-посилання таблиці витрат'
};
```

Після цього в розділі «Зараз» зʼявиться живий статус, а в «Грошах» — баланси
(«спільне» ділиться на шістьох; «особисте» в баланс не входить).

Окремо дайте доступ на **редагування** пʼятьом іншим — Share → додати пошти.
Публікація CSV лише читає; редагують через звичайний доступ.

## Правила, на яких це тримається

- Обговорюємо в чаті — **рішення переносимо в план**. Чого немає в плані, того не домовлено.
- Змінює план одна людина (координатор), одним повідомленням «оновив: що саме».
- Версія й дата — у підвалі сайта; піднімайте їх при кожній зміні.
- Галочки й вписані імена на сайті — **особисті, для одного пристрою**. Спільне — тільки в таблицях.
- Офлайн-копія і PDF — резерв на дорогу, не основна версія.

## Як редагувати

`index.html` — звичайний HTML, ніякого збирання. Відкрити у браузері — і все працює.
Після змін офлайн-копію треба перегенерувати (або попросити мене).
